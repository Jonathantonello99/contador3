# Contador de Graos V3 - projeto limpo

Projeto refeito do zero para Chrome e GitHub Pages.

## Publicar
1. Crie um repositorio NOVO e vazio no GitHub.
2. Envie os arquivos e pastas deste pacote para a raiz. Nao envie a pasta node_modules e nao envie dist.
3. Confirme que existem `src/App.jsx`, `src/main.jsx` e `.github/workflows/deploy.yml`.
4. Em Settings > Pages > Source escolha GitHub Actions.
5. Faça um commit na branch main e aguarde o workflow Deploy GitHub Pages.

## Uso
1. Abra a URL HTTPS do GitHub Pages no Chrome e permita a camera.
2. Fundo vazio: clique CALIBRAR FUNDO.
3. Coloque 20-50 graos separados e clique APRENDER PERFIL DOS GRAOS.
4. Coloque a amostra completa.
